Lessons learned

El index no es el punto de uso de un step split
request-execute/close/intake-explore son index/redirect (split HOR-059/086). El LLM carga el index y luego el sub-archivo de fase, que es donde realmente ejecuta. Poner el re-surfacing solo en el index establece intención pero puede no repetirse al cargar task-loop.md durante el bucle de tasks. → B1 (`should`): repetir el pointer en los sub-archivos de fase críticos.
Un placeholder genérico cuesta saliencia
El reviewer marcó que <dets> introducía un nivel de indirección — un LLM nuevo no sabe si reemplazarlo. Un ejemplo concreto al lado ([20,23,25]) elimina la ambigüedad. Lección replicable: en instrucciones point-of-use, el ejemplo concreto pesa más que el placeholder abstracto.
a-hook conceptual ≠ runtime — decir cuál es
El comentario dice explícito "(conceptual, HOR-087)" porque los a-hooks no son hooks runtime del harness hoy. Marcarlo evita la ilusión de enforcement. Cuando exista la infra runtime (RULE-009 capa 5) hay que actualizarlo → B2 (`could`).
