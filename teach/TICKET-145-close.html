Aprendizajes

Denylist regex para href es inseguro. /^\s*(javascript|data):/i se elude ofuscando el esquema con control chars vía entidad numérica (java&#9;script:) y no cubre vbscript:/file:. Regla: usar allowlist de esquemas (http/https/mailto + relativas/anclas) normalizando [\x00-\x20] antes de evaluar. Aplica a AMBAS capas: blindar solo el server no alcanza si el cliente es la defensa primaria del render.
Twin JS de lógica TS. logic/ corre en object-manager (Node plano, sin transpile TS): no puede importar los .logic.ts. Se replica en twin JS (patrón buildRequirementTree.js/.ts) — vigilar drift. Además: la electividad se DERIVA de blockId != null (no hay flag persistido), y la unicidad/renumerado sin constraint dejan ventana de carrera bajo Read Committed (documentado, endurecimiento diferido).
