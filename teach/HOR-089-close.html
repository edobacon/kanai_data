El punto de uso de un step split es el sub-archivo, no el index
Confirmó el invariante del intake: para steps split, el re-surfacing debe vivir en el sub-archivo de fase (donde el LLM está durante el task-loop), no solo en el index. HOR-087 había cableado el index; esto completa el punto de uso real para request-execute.
El set por-fase es lo que da valor (y trabajo)
La parte mecánica (pegar snippet) fue trivial; el valor estuvo en elegir el dets de cada fase derivándolo de sus gates reales — start gatea init/guards (20,28,29,30), task-loop gatea TC/persistencia (9,10,25,29), etc. Copiar el set del root habría sido ruido.
Proporcionalidad de gates en un T1
Quality review inline light + validación de cierre inline (no sub-agente): el cambio era mecánico y el patrón ya fue revisado aislado en HOR-087. Reservar el reviewer aislado para T2/T3/⚑ fuerte (DET-30 proporcionalidad por tier).
