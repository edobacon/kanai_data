Lecciones

Un módulo puro ya extraído acelera la paridad entre superficies
blockSelect.logic era Vue-free/GraphQL-free y ya testeado; darle la capacidad a la edición fue wiring, no lógica nueva. Vale la pena revisar si una capacidad "que falta" en un lugar ya existe extraída en otro.
Agregar una opción a un <select> rompe tests de conteo — actualizarlos con el cambio
El test existente asertaba placeholder + N opciones. Al sumar "crear nuevo" el conteo cambió (3→4); es un cambio intencional del REQ, así que el test se actualiza (no se elude) y se agregan tests para la conducta nueva.
Doble icono/afijo: revisar icono + etiqueta juntos
Un botón con icon + etiqueta que empieza con el mismo símbolo duplica el glifo. Al usar el atom Button con icono, la etiqueta i18n no debe repetir el símbolo.
