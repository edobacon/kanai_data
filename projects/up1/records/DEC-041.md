# Add Atlassian Rovo MCP server to opencode.json

## Context and problem statement

El usuario necesita conectar opencode con Jira para trabajar con tickets de Atlassian. Actualmente solo tiene el MCP de deckard-cain configurado. Se evaluaron 3 opciones (Rovo oficial, atlassian-cli community, mcp-atlassian community) y se eligió Rovo oficial por ser el más directo para Atlassian Cloud.

## Decision drivers

- Conectar opencode con Jira para buscar/crear/actualizar tickets directamente desde el LLM
- Evitar context-switching entre opencode y la UI de Jira
- OAuth 2.1 con Dynamic Client Registration (sin crear app manualmente en Atlassian admin)

## Considered options

### Option A: atlassian-cli (community)
- **Pro**: Soporta Server/DC + Cloud, single binary, CI/CD friendly
- **Con**: Requiere instalar binary, no tiene OAuth nativo

### Option B: mcp-atlassian (community, Python)
- **Pro**: Soporta Server/DC + Cloud, Python-based
- **Con**: Requiere Python + pip install, más config


## Decision outcome

**Chosen option**: Atlassian Rovo MCP Server (oficial): endpoint https://mcp.atlassian.com/v1/mcp/authv2, OAuth 2.1, 72+ tools (Jira, Confluence, Compass)

## Consequences

### Positive
- Acceso directo a Jira desde opencode (search, read, create, transition)
- OAuth 2.1 con DCR: primera conexión abre browser, después auth automático
- 72+ tools disponibles (Jira, Confluence, Compass)

### Negative
- Requiere habilitar Rovo en el sitio Atlassian (site admin)
- Requiere habilitar Remote MCP server en admin
- Cloud-only (no Server/DC)

## Confirmation

Config guardada en opencode.json. Reiniciar opencode para que el MCP server se conecte.
