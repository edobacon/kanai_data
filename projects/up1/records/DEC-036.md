# Versionado/clonado de la malla con hijos: cascada generica config-driven en core (Alt A)

## Context and problem statement

Versionar/clonar un Curriculum debe copiar sus hijos (planEntry, requirementCategory, requirement owner=curriculum). El equipo autorizó modificar core para esto.

## Decision drivers

- Reusar la plataforma en vez de parchear caso por caso
- El motor de cascada (deepClone) ya existe en core
- Versionar un Curriculum está roto en core (BUG-core-003/004)

## Considered options

### Option A: Resolver táctico versionCurriculum en el mod
- **Pro**: No toca core
- **Con**: Duplica el walk de linaje; se aparta del patrón de activity; deuda

### Option B: Copia de hijos custom en el mod
- **Pro**: Acotado
- **Con**: No generaliza; la copia de hijos es mecánica de plataforma


## Decision outcome

**Chosen option**: Cascada GENÉRICA config-driven en core (Alt A): el deep-copy de hijos lo dispara la metadata del contenedor (prefillFrom.deepClone + directChildren/polymorphicChildren) sobre el motor existente; + fix del versionado de objeto con RecordType. Se descarta el parche táctico mod-only.

## Consequences

### Positive
- Capacidad de plataforma reusable para cualquier objeto contenedor futuro

### Negative
- Es trabajo de core con review del team (RULE-dev-004); diferido a SP6; gated por BUG-core-003/004

## Confirmation

2026-06-23: el equipo autoriza tocar core para versionado/clonado.
