# SP5 implementa solo planes secuenciales (modular se difiere)

## Context and problem statement

La malla puede ser secuencial (con períodos/semestres) o modular (orden derivado del DAG de prerrequisitos). Hay que acotar el primer incremento del componente.

## Decision drivers

- Establecer una base clara y funcional (MVP) antes de complejidad adicional
- Los planes secuenciales son la base del producto
- Capacidad del sprint

## Considered options

### Option A: Incluir planes modulares en SP5
- **Pro**: Feature más completa
- **Con**: El componente debe mostrar niveles derivados del DAG; sube riesgo y alcance sin una base estable


## Decision outcome

**Chosen option**: SP5 implementa SOLO planes secuenciales: planEntry.period es requerido. El caso modular (period nullable + orden por DAG, componente que muestra niveles) se difiere.

## Consequences

### Positive
- Base clara y funcional
- planEntry.period requerido simplifica el modelo y la validación

### Negative
- planEntry modular (period nullable + DAG) queda pendiente (SP6, BL-6)

## Confirmation

Acordado en reunión de inicio (00:55:49); el enum progression {Sequential, Modular} deja la puerta abierta.
