Resultado para el usuario

Qué puede hacer un diseñador al terminar SP5

1 · Ver

Abrir un plan y ver su malla organizada por períodos, cada asignatura en una tarjeta con código, créditos, línea (color/ícono) y badge de electivo.

2 · Agregar

Añadir asignaturas del catálogo: obligatorias (en masa a una línea) o electivas dentro de un bloque con nombre ("elegir 4").

3 · Editar / quitar

Cambiar créditos, línea de formación, rol obligatoria↔electiva, o quitar la asignatura de la malla.

4 · Filtrar

Resaltar por línea y por bloque electivo, con rollup de créditos por línea y botón limpiar.

5 · Reorganizar

Drag&drop entre semestres (persiste período/posición) + agregar período; alerta si faltan prerrequisitos al agregar.

6 · Gestionar líneas

Pestaña CRUD de líneas de formación: nombre, código, créditos mín/máx, color e ícono, con estado de crédito (incompleta/en rango/excedida).

La base técnica

Los 3 objetos de datos nuevos

Todo se apoya en un modelo copiado de CurricularSection (ya en producción): FK polimórfica, self-FK y múltiples RecordTypes. Los valores calculados (créditos efectivos, electividad, estado) son derivados en lectura (enrichment), no columnas persistidas.

planEntry

Una asignatura colocada en la malla: en qué plan, período, línea, y si es obligatoria o electiva.

FKs a Curriculum / Activity / requirementCategory · enum kind · blockId ≠ null ⇒ electiva.

requirementCategory

Una línea de formación — bucket de créditos (ej. "Ciencias Básicas") con mín/máx, color e ícono.

Guard de borrado: no se elimina si tiene entries asignados (FK Restrict + validación).

requirement

Una regla como árbol (Composite). 3 RecordTypes: Group (K-de-N, electivos), RecordState (prereqs), MetricThreshold (umbral de créditos).

FK polimórfica ownerType/ownerId + self-FK parentId.

Reglas de plataforma re-confirmadas: los mods no registran type resolvers de GraphQL (enrichment en el override de lectura) · nullability por required[] · enums base son enum Postgres, enums de RecordType son texto (soft). Promovido a RULE-curriculum-design-017/018.

logic/helpers/buildRequirementTree.js (recortado)
export function buildRequirementTree(items) {
  const byId = new Map();
  for (const it of items) byId.set(it.id, { ...it, children: [] });
  const roots = [];
  for (const node of byId.values()) {
    const hasParent = node.parentId != null && byId.has(node.parentId);
    if (hasParent && hasCycle(node.id)) { roots.push(node); continue; }
    hasParent ? byId.get(node.parentId).children.push(node) : roots.push(node);
  }
  return sortByPosition(roots);
}

export function groupByPeriod(entries, totalPeriods, categories = [], viewPeriodCount = 0) {
  const maxEntry = entries.reduce((m, e) => Math.max(m, e.period || 0), 0)
  const requested = viewPeriodCount > 0 ? viewPeriodCount : totalPeriods
  const columnCount = Math.max(maxEntry, requested, 0)
  const columns = Array.from({ length: columnCount }, () => [])
  for (const e of entries) {
    const idx = e.period - 1
    if (idx >= 0 && idx < columnCount) columns[idx].push(toCard(e, categories))
  }
  return columns
}

export function deriveCreditStatus({ currentCredits, minCredits, maxCredits }) {
  const current = Number(currentCredits ?? 0)
  const min = minCredits == null ? null : Number(minCredits)
  const max = maxCredits == null ? null : Number(maxCredits)
  if (min !== null && current < min) return 'under'
  if (max !== null && current > max) return 'over'
  return 'ok'
}

export function recalcPeriodPosition({ movedEntryId, fromPeriod, toPeriod, toIndex, entries }) {
  const moved = entries.find(e => e.id === movedEntryId)
  if (!moved) return []
  if (fromPeriod === toPeriod) {
    const siblings = sortByPosition(entries.filter(e => e.period === fromPeriod))
    const without = siblings.filter(e => e.id !== movedEntryId)
    const idx = Math.max(0, Math.min(toIndex, without.length))
    without.splice(idx, 0, moved)
    return reindex(without, fromPeriod)   // position 0-based
  }
  // cross-columna: reindexa destino + origen (cierra el hueco)
}

export async function assertActivityNotInActivePlan({ prisma, ownerType, ownerId }) {
  if (ownerType !== 'activity' || ownerId == null) return
  const entries = await prisma.planEntry.findMany({
    where: { activityId: ownerId }, select: { planId: true } })
  const planIds = [...new Set(entries.map(e => e.planId).filter(Boolean))]
  if (!planIds.length) return
  const active = await prisma.curriculum.findMany({
    where: { id: { in: planIds }, status: { in: PUBLISHED_STATUSES } } })
  if (active.length) throw new Error(`${ERR.REQUIREMENT_ACTIVITY_LOCKED_BY_ACTIVE_PLAN}: …`)
}
