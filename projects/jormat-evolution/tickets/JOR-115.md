# JOR-115 · Test scripts del front deterministas (jsdom por defecto, stories aparte)

## Request

`npm test` (`vitest run`) corria los DOS proyectos vitest (jsdom + storybook/browser), pero el proyecto
storybook/browser esta excluido de CI/coverage por flakiness (comentario en `vitest.config.ts`). Resultado:
`npm test` local mostraba flakes fantasma que CI no ve. Alinear `test` con CI.

## Cambio (tactic)

- `test`: `vitest run --project '!storybook'` (solo jsdom, como CI/coverage).
- `test:watch`: `vitest --project '!storybook'`.
- **nuevo** `test:stories`: `vitest run --project storybook` (stories en browser-mode, opt-in, tolerante a su flakiness).

Solo `front/jormat-front/package.json`. La estabilizacion del proyecto browser en si queda como follow-up **JOR-116**.

## Verificacion

`npm test src/lib/schemas/payments.test.ts` → corre `--project '!storybook'`, 22/22. Suite jsdom completa 1784/1784.
