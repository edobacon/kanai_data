# Ocultar "guardar borrador" de forma consistente (Ventas + Compras)

## Request

Objetivo: mientras el borrador siga "no presupuestado", que NO se ofrezca guardar borrador en NINGUN punto de la factura (de venta ni de compra). Hoy el boton de la toolbar esta oculto pero el modal de confirmacion al salir sigue ofreciendo "Guardar borrador".

Caso: X-BORRADOR-01 (reportado por el dev 2026-08-08).

Causa raiz (mapeada): `SHOW_SAVE_DRAFT=false` solo gatea el boton de la toolbar (`TransactionBuilder.tsx:433`, `PurchaseInvoiceBuilder.tsx:260`). El modal de salida es independiente: ambos builders pasan `onSaveDraft: handleSaveDraft` al guard sin condicionar por el flag (`TransactionBuilder.tsx:401-403`, `PurchaseInvoiceBuilder.tsx:229-231`), y `NavigationGuardProvider.tsx:217` renderiza el boton "Guardar borrador" del `UnsavedChangesDialog` siempre que haya un draft handler registrado.

Puntos que ofrecen guardar borrador (unicos consumidores): (1) toolbar ventas `TransactionBuilder.tsx:433`; (2) toolbar compras `PurchaseInvoiceBuilder.tsx:260`; (3) modal de salida ventas via `onSaveDraft` `TransactionBuilder.tsx:403`; (4) modal de salida compras via `onSaveDraft` `PurchaseInvoiceBuilder.tsx:231`. `AplicarPagoView` (pagos) usa el guard SIN `onSaveDraft` (`AplicarPagoView.tsx:52`), ya correcto.

### Context found

- El flag `SHOW_SAVE_DRAFT=false` gatea solo la toolbar (`TransactionBuilder.tsx:433`, `PurchaseInvoiceBuilder.tsx:260`), no el modal de salida.
- El modal ofrece "Guardar borrador" porque el guard recibe `onSaveDraft: handleSaveDraft` sin condicionar por el flag (`TransactionBuilder.tsx:401-403`, `PurchaseInvoiceBuilder.tsx:229-231`); `NavigationGuardProvider.tsx:217` renderiza el boton mientras haya draft handler.
- Fix propuesto por el plan: `onSaveDraft: SHOW_SAVE_DRAFT ? handleSaveDraft : undefined` en ambos builders; un solo flag gobierna toolbar + modal.
- `NavigationGuardProvider`/`UnsavedChangesDialog` NO cambian (ya soportan `onSaveDraft` opcional; el bug es de wiring del consumidor). Toca los builders; serializar en la cadena builder-calc.
