# Validar pago de sucursal (estados validada/mixta/rechazada) + permiso + contraste del modal

## Request

En la vista de Pagos de sucursal, el modal "Detalle del pago" tiene problemas de contraste (los elementos no se ven bien) y falta la accion para validar el pago. Segun el legacy (visualizar-pago), un pago puede marcarse como **validada**, **mixta** o **rechazada**; esa capacidad debe estar controlada por un permiso. Crear un pago tambien debe estar bajo un permiso. Todo esto debe quedar documentado y con sus tests. Deben crearse los endpoints respectivos con sus stubs.
