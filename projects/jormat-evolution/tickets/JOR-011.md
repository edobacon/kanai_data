# JOR-011 · A6 · RBAC frontend (Usuarios + Roles/Permisos)

## Request

Construir las dos vistas de administración de cuenta: vista Usuarios (DataTable + form alta/edición + soft-disable + asignación de roles) y vista Roles y Permisos (maestro-detalle + matriz de toggles `recurso:acción` + filtros por módulo/feature), según el prototipo HTML `drafts/prototipo.html` y el modelo de `permissions-by-view.md`. Source: `jormat_docs/ongoing/implementation-tasks.md` (WP-A6 · A6.5–A6.8) + `jormat_docs/ongoing/permissions-by-view.md`.
