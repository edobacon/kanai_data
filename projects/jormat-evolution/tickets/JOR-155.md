# Alinear fixtures MSW del front (ventas/compras) al itemId uuid

## Request

Cerrar **JOR-149 B2** (de [[SPEC-JOR-149-identidad-serial-uuid-inventario]]): tras el pase a identidad serial+uuid del dominio (JOR-148/JOR-149), los fixtures del front todavia hablan en el molde viejo. Alinear los MSW handlers (`handlers/{ventas,purchases}.ts`) y las stories de ventas/compras al `itemId` **uuid**, para que el front de prueba refleje el contrato real del backend.

Es deuda de consistencia de datos de test: si los fixtures emiten un id que ya no es el que el backend expone, las stories/tests validan contra un contrato desactualizado.
