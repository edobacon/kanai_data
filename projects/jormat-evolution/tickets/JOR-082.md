# T-CAT-BK · Dinamizar servicios de catalogos a DB (modelo ya existe)

## Request

Dinamizar el servicio de catalogos (hoy stub in-memory, JOR-057) para leer las tablas reales. El modelo EXISTE para categorias, aplicaciones, proveedores, bodegas, ubicaciones, camiones (migracion de inventario). Normalizar el drift de naming `catalogos:view` (2 segmentos) vs `items.catalogs:view`. Faltan `formas_de_pago` y `catalogos` (entidad persistida): si no existen, dejar stub con DEUDA_TECNICA.
