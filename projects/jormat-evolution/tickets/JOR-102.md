# JOR-102 · Cleanup: retirar el alias deprecado `formatCLP`

## Request

Migrar los usos del alias deprecado `formatCLP` (de `lib/format.ts`) a `formatCurrency('CLP')` de
`lib/currency.ts` (fuente única, JOR-017) y eliminar el alias + su test redundante. Deuda registrada
al cerrar JOR-079. Drop-in, sin cambio de comportamiento.

## KB consulted (DET-11)

- JOR-017 consolidó la lógica de moneda en `lib/currency.ts`; `formatCLP` quedó como alias
  retro-compatible marcado `@deprecated`. No hay spec activo ni rule normativa que la migración
  viole. `currency.test.ts:34` ya asegura la salida ("Salida fiel al formatCLP previo") → al quitar
  `format.test.ts` no se pierde cobertura.
- Nota de escalamiento: el cambio toca >3 archivos (heurístico tactic), pero es un reemplazo
  mecánico drop-in idéntico (cero lógica nueva). Heurístico = falso positivo; se procede como tactic.

## Discoveries / decisions

- `formatCurrency(amount, currency='CLP')` tiene default CLP → drop-in tanto en call-sites
  (`formatCLP(x)` → `formatCurrency(x, 'CLP')`) como en referencias de función
  (`currencyFormatter = formatCLP` → `= formatCurrency`).
- 15 call-sites en 8 archivos + 3 archivos del builder que lo usan como default de prop.
- `lib/format.ts` solo contenía `formatCLP` → se elimina el archivo + `format.test.ts` (redundante).
