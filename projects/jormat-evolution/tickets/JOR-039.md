# Modernizar convenciones de codigo: guardarrail ESLint + refactors acotados (switch / ternario)

## Request

El dev pidio revisar el codigo del proyecto para actualizarlo a convenciones modernas
de JS/TS: usar `===` en vez de `==`, arrow functions salvo cuando se necesite `this`,
ternarios para `if` simples, `switch` en vez de cadenas de `if` de comparacion de estado,
declarar variables con `const`, y demas buenas practicas. Analizar el codigo, crear un
ticket con los casos detectados, refactorizar, y luego correr los tests correspondientes.

> **Reencuadre acordado con el dev (intake, 2026-06-23)**: el analisis empirico mostro que
> lo mecanico (`==`, `var`, `let`→`const`) ya esta limpio (0 casos en codigo nuestro). El
> alcance se acoto a **guardarrail ESLint + refactors acotados de alto valor** (decision del
> dev: "Guardarrail + switch/ternario") y **solo codigo nuestro** (respetando RULE-global-003).
> El request original NO se reescribe (DET-3) — este blockquote documenta la calibracion.
