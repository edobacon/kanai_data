# JOR-118 · Ocultar boton "Guardar/Crear borrador" (no presupuestado) + alinear tests

## Request

Cambio del dev: el borrador (guardar/crear borrador) no esta presupuestado en este alcance. Ocultar el
boton en los builders de ventas y compras, dejando el codigo (handler + wiring) intacto para reactivar.

## Cambio (tactic)

- `TransactionBuilder.tsx` (ventas) y `PurchaseInvoiceBuilder.tsx` (compras): boton de borrador envuelto
  en `{SHOW_SAVE_DRAFT && (...)}` con `const SHOW_SAVE_DRAFT = false`. Handler `handleSaveDraft` intacto.
- **Alineacion de tests (Opcion A, elegida por el dev)**: los asserts de "muestra el boton" pasan a
  "oculto" (2); los tests del flujo de borrador (POST /draft, toasts, disabled, error mapping) quedan
  `describe.skip` con comentario "reactivar junto con el boton" (11 skipped). No se borran: se preservan.

## Impacto / follow-up

- `handleSaveDraft` queda sin cobertura de test mientras el boton este oculto (baja algo el % del front).
  Al reactivar (`SHOW_SAVE_DRAFT = true`), quitar los `.skip` restaura la cobertura.
