# T-PLAT-02 · RBAC por campo (cerrar gap de inputs sensibles)

## Request

Cablear en el front las capabilities de campo que YA existen en el catalogo pero no se usan (`items.parts:critical`, `items.parts:matrix`, `items.parts:priority`) sobre los campos/inputs sensibles, y decidir el caso `permiso-especial-view` (costo/margen/precio minimo). ## Context found

- API de gating: `<Can cap="module.feature:action">` + `useCan(cap)` (`components/auth/Can`, `hooks/useCan`). Oculta en UI; backend revalida.
- Capabilities `items.parts:critical/matrix/priority/view/edit` YA existen (seed `04_items_capabilities.ts`); NINGÚN input del front las usa aún (gap).
- `ItemCreateForm` (sirve create Y edit) tiene los inputs sensibles: `marca`/`codigoMarca`/`proveedores` (matrix) y `precios.compraNeto`/`precios.compra`/`precios.porMayor`/`oferta` (cost/critical). Campos de costo son `required`.
- `ItemDetailModal` (view) muestra marca/codigoMarca/proveedores (matrix); NO muestra costo (no está en el DTO de lectura).
- Panel de pagos `AplicarPagoView` gateado a nivel ruta por `payments.customers:view`.
- Fuera de scope (no existen): valor moneda, precio mínimo, panel Precios completo, columna reportes.
- Seeding de caps→roles: `04_items_capabilities` (catálogo), `09_internal_admin_grant_all` (todo a internal-admin), `10_demo_roles_users` (subsets: jefe-local/jefe-venta=JEFE_CAPABILITIES con critical; gerencia con critical; cajero con critical; vendedor solo view; bodega sin critical).

## Decisiones

- **DEC-LOCAL-1** — Alcance = **full incluyendo create** (dev). El form de create/edit gatea campos sensibles; los de costo (required) pasan a opcionales + default cuando el usuario no tiene la capability, para no romper el submit.
- **DEC-LOCAL-2** — **Crear capability `items.parts:cost-view`** (dev) para costo/margen (permiso-especial-view no tenía equivalente). Los campos de costo se gatean con cost-view; matrix (proveedores/marca/código) con `items.parts:matrix`; oferta con `items.parts:critical`.
- **DEC-LOCAL-3** — `cost-view` asignada a **gerencia + jefe-local + jefe-venta + internal-admin** (dev). Más restrictiva que critical (cajero NO ve costo). Rationale: costo/margen es el dato más sensible.
