## Diagnostico (test error vs regresion)

Los 3 son **errores de test (stories stale)**, NO regresiones del componente. El componente se comporta como fue diseñado; las stories no se sincronizaron con cambios intencionales:

| Story | Assert que fallaba | Causa raiz | Veredicto |
|-------|--------------------|------------|-----------|
| Home/Default | `getByText('Inicio')` + `getByText('Próximamente')` | JOR-032 quito el tile "Inicio" (el lanzador filtra `path !== '/'`); JOR-017 habilito Reportes (ya no hay tile "Próximamente") | test stale |
| Sidebar/Expanded | `getByText('Finanzas')` | El sidebar gatea nav por capability (JOR-008). La story NO sembraba `capabilities`; el grupo Finanzas (children full cap-gated) quedaba oculto | test stale (mock incompleto) |
| Sidebar/WithActiveRoute | link `Items` | idem — `items.parts:view` no sembrada → item oculto | test stale (mock incompleto) |

Evidencia: `Home.test.tsx` (que pasa) ya asume `queryByText('Inicio')` ausente (JOR-032) y Reportes con `href="/reportes"` (JOR-017); `Sidebar.test.tsx` (que pasa) mockea `capabilities: ['*']` (JOR-014). Las stories no replicaban eso.
