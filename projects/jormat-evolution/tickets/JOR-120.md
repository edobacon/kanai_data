# Descuento global como % + control en UI (Ventas + Compras)

## Request

Objetivo: el descuento global debe ser un porcentaje (fiel al legacy), con input en la UI y cap (ventas 0-20, compras 0-30), recalculando el total como `neto - (desc*neto/100)`.

Casos: V-03, C-03, C-04. Extiende D2/DEC-018 (que solo cerro el descuento por LINEA).

NO es un revert: el descuento de LINEA ya es porcentaje (correcto, DEC-018, commit `b085ffd` 2026-08-08). El descuento GLOBAL es un constructo distinto que se introdujo el 2026-07-05 (JOR-065-S7) restandose como MONTO y sin control en la UI (comentario literal en `calc-totals.ts`: "constructo nuevo que se resta como monto"). Ninguna decision eligio "monto" para el global; es un gap, no una decision a revertir. Este ticket lo pasa a % (como el legacy) y le agrega el input.
