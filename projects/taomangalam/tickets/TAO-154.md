## Objetivo
Resultado: evidencia reproducible de que Flutter 3.47.2 compila para iOS Simulator y Android con
todos los plugins nativos juntos sobre iOS 15 y API 24, y una salida explícita: baseline aprobado
o DEC nueva si un plugin obliga a subir un mínimo. Consumidor: criterio de cierre de EP-00 y el
`pubspec.yaml` definitivo que usan EP-01, EP-06 y las épicas con plugins nativos.

Pregunta: ¿el conjunto de plugins nativos previsto compila y arranca junto sobre los mínimos de
DEC-198 sin degradar ni duplicar plugins? Timebox: equivalente a 3 puntos; el límite en días se
fija al planificar la iteración (doc 46 §1).

## Alcance
**Incluye**
- PR vertical sobre el esqueleto de HU-00-02 con las seis familias de tecnologia/24: DB (`drift` y
  `sqlite3_flutter_libs`), seguridad (`flutter_secure_storage`), scanner (`mobile_scanner`), audio
  (`record` y `just_audio`), notificaciones (`flutter_local_notifications` y `timezone`) y
  background (`workmanager`).
- El resto de dependencias nativas P0 y P1 de tecnologia/16: `connectivity_plus`,
  `package_info_plus`, `device_info_plus`, `url_launcher`, `path_provider`, `permission_handler`,
  `image_picker`, `file_picker`, `share_plus`, `google_sign_in` y `sentry_flutter`.
- Build iOS Simulator y Android debug; arranque en AVD API 24 y API 36 y en Simulator con el
  runtime más bajo disponible; una tarea WorkManager trivial registrada y ejecutada.
- Kotlin, Gradle, AGP y Xcode usados quedan fijados en configuración tras el primer build limpio
  (DEC-198).
- `pubspec.lock` y reporte de licencias de dependencias.
- Informe en el issue del spike (doc 48 §7): matriz plugin, versión, mínimo exigido y resultado,
  más la decisión.

**No incluye**
- Express, Prisma, `pg-boss` y migración desde cero (puntos 3 y 4 de tecnologia/24): HU-00-04 a
  HU-00-08.
- Adapters fake de CloudKit y Drive, PDF por streaming, símbolos de Sentry y smoke de Socket.IO
  (puntos 4 a 6 de tecnologia/24): épicas que incorporan esas piezas, fuera de EP-00.
- Interfaces propias y uso productivo de cada plugin: épicas consumidoras.
- Escenarios de tecnologia/16 sobre permisos revocados, nube sin cuota o red cautiva: épicas
  consumidoras.

## Criterios de aceptación
- [ ] Dado el PR vertical, cuando se ejecutan `flutter build ios --simulator` y
  `flutter build apk --debug` con todos los plugins declarados, entonces ambos terminan con
  código 0.
- [ ] Dado el APK, cuando se instala en AVD API 24 y API 36, entonces la app arranca sin cierre
  inesperado y la tarea WorkManager de prueba deja su log de ejecución.
- [ ] Dado un plugin que exige iOS mayor que 15 o `minSdk` mayor que 24, cuando se detecta,
  entonces no se degrada ni se reemplaza por una librería equivalente: se registra una DEC nueva
  con el mínimo propuesto o una alternativa comparada antes de cerrar el spike (tecnologia/24).
- [ ] Dado el primer build limpio, cuando cierra el spike, entonces las versiones de Kotlin,
  Gradle, AGP y Xcode quedan anotadas en el informe y fijadas en la configuración del proyecto.
- [ ] Dado el cierre, cuando se revisa el issue, entonces contiene la matriz de plugins, el
  reporte de licencias, el `pubspec.lock` resultante y la lista de historias afectadas.
