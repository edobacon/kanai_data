## Objetivo
Resultado: la documentación se valida en cada PR con MkDocs, markdownlint, Vale, cspell y Lychee,
y el contrato se renderiza con Redocly, con adopción incremental sobre los documentos existentes.
Consumidor: todo PR con impacto documental (DEC-193) y EP-03a, que reutiliza esta base para
publicar documentos legales.

## Alcance
**Incluye**
- `mkdocs.yml` con MkDocs Material de versión fijada en un `requirements.txt` con versiones
  exactas, instalado con Python 3.12, y navegación inicial sobre `docs/` (DEC-230).
- Vale y Lychee ejecutados en CI mediante sus GitHub Actions fijadas por SHA completo (DEC-230).
- `markdownlint-cli2` (`.markdownlint-cli2.yaml`), Vale (`.vale.ini` con estilo Tao Mangalam de
  terminología), cspell (`.cspell.json` con diccionario de dominio y español) y Lychee: enlaces
  internos en cada PR y externos con reintento en `nightly.yml` (tecnologia/19 §7).
- Redocly CLI `build-docs` sobre el contrato ya validado por Spectral.
- Baseline versionada de documentos heredados: reglas completas en archivos nuevos o modificados;
  los heredados sin tocar no bloquean (tecnologia/19 §4 y §13).
- Comandos `pnpm docs:serve`, `docs:check:changed`, `docs:check`, `docs:preview` y `docs:api`
  (solo Redoc en M0).
- Ampliación del job `docs` de `ci-pr.yml` y build completo del sitio en `main.yml` como artifact.

**No incluye**
- Validador de frontmatter con Ajv, Mermaid CLI, `dart doc`, TypeDoc y detección de documentos
  huérfanos (tecnologia/19 §10): HU-00-18.
- Hosting o publicación del portal: sin decisión; el sitio se entrega como artifact.
- Publicación de documentos legales: EP-03a.

## Criterios de aceptación
- [ ] Dado el repositorio, cuando se ejecuta `pnpm docs:preview`, entonces el sitio compila sin
  enlaces internos rotos.
- [ ] Dado un PR que modifica un documento con un enlace interno roto, cuando corre `docs`, entonces
  Lychee falla.
- [ ] Dado un término fuera del diccionario en un archivo nuevo, cuando corre cspell, entonces
  falla; un heredado en la baseline que no se modifica no bloquea.
- [ ] Dado un error de markdownlint o de Vale en un archivo modificado, cuando corre `docs`,
  entonces falla; una sugerencia de Vale solo informa.
- [ ] Dado un contrato con error de Spectral, cuando corre el job, entonces Redocly no se ejecuta y
  el job queda rojo; con contrato válido se publica la referencia HTML como artifact.
- [ ] Dado un enlace externo caído, cuando corre el PR, entonces no falla; `nightly.yml` lo
  informa.
- [ ] Dado un merge a `main`, cuando corre `main.yml`, entonces publica el sitio completo como
  artifact.
- [ ] Dado el job `docs`, cuando se inspecciona, entonces MkDocs se instala desde el
  `requirements.txt` fijado y las Actions de Vale y Lychee están referenciadas por SHA completo, no
  por etiqueta.
