# Fix bugs DET-29 hallados en HOR-024 (set_fm_field + stub gate decision)

## Request

Dos bugs preexistentes del flujo DET-29 detectados durante la ejecucion de HOR-024 (registrados como learns L1/L2). El dev pidio corregirlos.

**Bug A (L1, bloqueante retro-compat)**: `set_fm_field` en `commands/dkc-execute-task` (~L172-194) solo REEMPLAZA campos del frontmatter que ya existen (el awk hace `$0 ~ "^"f":"`). Si el campo no existe, `done` nunca se setea y el campo NO se agrega. Sintoma: tickets pre-DET-29 (creados < 2026-05-22) sin `current_session` en frontmatter → `init-ticket` reporta "current_session: null → N" pero no persiste el campo → exit 1. Observado en HOR-024 (workaround: agregar `current_session: null` manual).

**Bug B (L2, doc inconsistente)**: el stub canonical de session al ABRIR no debe incluir el bloque `**Gate decision:**` — el validator `SessionBlock` lo rechaza con `decision: null`, y `close-gate` lo inserta al cerrar. Pero `request-execute/start.md` (L53-62) y `templates/records/ticket.md` (L231-235) muestran el bloque Gate decision como parte del stub de apertura → contradiccion que hace fallar `init-ticket`/validacion al abrir.
