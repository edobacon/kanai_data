## Request

**Ticket exploratorio conditional**. Origen: cierre HOR-029 (2026-05-15). En HOR-029 se evaluo Ruta A vs Ruta B, dev eligio Ruta B primero (bajo costo, reversible, validable empirico). Ruta A queda como follow-up **explicitamente condicional**: se activa SOLO si en proximos tickets emerge evidencia de que Ruta B es insuficiente.

**Que es Ruta A**: MCP server custom (extension del existente `deckard-cain` o nuevo `dkc-multi-agent`) que registre los `subagent_type` de DKC (researcher, scribe, developer, reviewer, architect, tester) como agentes invocables NATIVAMENTE en el host Claude Code. A diferencia de Ruta B (mapping a agentes del host como Explore/Plan/general-purpose), Ruta A registra los roles DKC con sus capabilities exactas + restrictions enforced server-side.

**Por que Ruta A podria ser necesaria** (problemas que Ruta B no cubre):

1. **Cobertura 4/6 roles**: Ruta B no mapea `developer` ni `scribe` (no hay equivalente del host con `[edit, write, git_commit]`). Estos roles consumen el grueso del trabajo en tickets de codigo real → su contexto sigue cayendo al principal. Si DET-15 emerge en tickets implement/fix grandes, Ruta A justifica.

2. **Restrictions via prompt-guard fragiles**: para `reviewer`/`tester` Ruta B usa `general-purpose` con prompt-guard tipo "READ-ONLY: no Edit/Write". HOR-029 S4 valido empirico que funciona en 1 test, pero **no es estadistico**. Si en N tickets el agent ignora el prompt-guard y modifica algo no autorizado, Ruta A enforced server-side seria la solucion robusta.

3. **Tier semantics no respetada**: el host actual ignora el `tier=fast | balanced | reasoning` del bloque AGENT INVOCATION. Para Setup local-only (roadmap HOR-032..038) la tier resolution real es CRITICA — Ruta A puede implementar el routing tier → modelo en el server.

4. **Cross-validation con modelos divergentes (D11 amplificado)**: Ruta A permite registrar `reviewer` apuntado a Gemini 2.5 Pro mientras `developer` usa Claude sonnet. Diversidad de pretraining → detecta errores que ejecucion single-model no captura. Ruta B no permite esto facil.
