# Context diet seguro de steps — extraer legacy + split lazy-load + consistencia scoping

## Request

**Origen**: análisis de economía de contexto (2026-05-30). Agrupa **wins mecánicos 100% seguros** (sin riesgo de degradar calidad de ejecución — a diferencia de HOR-085 que toca saliencia de reglas, esto es solo "dejar de cargar lo inútil o lo entero").

**Tres frentes**:

1. **Extraer v1 legacy de teach-intake/teach-close** — `teach-intake.md` (~127 líneas) y `teach-close.md` (~98 líneas) contienen bloques v1 dentro de `<details>` explícitamente marcados "NO usar para tickets nuevos" (post-2026-05-29). Se cargan íntegros igual. Mover a `teach-intake-legacy.md` / `teach-close-legacy.md` referenciados condicionalmente (solo tickets pre-2026-05-29). ~225 líneas de dead code eliminadas del contexto de cada ticket nuevo.

2. **Split lazy-load de steps pesados no divididos** — aplicar el patrón probado de HOR-059 (índice + sub-archivos por fase + `dkc_get_step_phase`) a:
   - `teach-intake.md` (34KB)
   - `teach-close.md` (30KB)
   - `intake-explore.md` (25KB)
   Cada uno tiene fases claras (gate + instrucciones + ejemplos). Se cargan 1x por ticket, pero siguen siendo 25-34KB por turno; en sesiones largas el split evita recargas completas.

3. **Consistencia de scoping de rules por módulo** — `design-feature.md` (línea ~12) y `tactic-execute.md` leen `projects/{project}/rules/` completo, mientras sus hermanos `design-improvement/fix/refactor` ya leen `rules/{module}/`. Alinear `design-feature` y `tactic-execute` a `rules/{module}/`. En up1 (115 rules / 272KB) esto pasa de "leer todo" a "leer el módulo del ticket". **Seguro**: el módulo del ticket es donde viven las rules relevantes; el descubrimiento cross-módulo se cubre aparte (backlog #2 de HOR-085, vía semantic search).

**Por qué separado de HOR-085**: HOR-085 toca la saliencia de las reglas (requiere validación de adherencia, tiene riesgo). HOR-086 es puramente mecánico — extraer dead code, split de archivos, alinear un glob. Cero riesgo de calidad → se puede ejecutar rápido y en paralelo.

**Alcance**:

- `prompts/steps/teach-intake.md` + nuevo `teach-intake-legacy.md`
- `prompts/steps/teach-close.md` + nuevo `teach-close-legacy.md`
- Split de `teach-intake.md`, `teach-close.md`, `intake-explore.md` (índice + sub-archivos, patrón HOR-059)
- `prompts/steps/design-feature.md` + `tactic-execute.md` — scoping `rules/{module}/`

**Repos tocados**: `deckard` (prompts/steps)
