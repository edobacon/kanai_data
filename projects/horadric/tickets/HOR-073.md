# Chip clickable de task.commit en SessionDetailModal — link al panel Commits

## Request

Post-HOR-072 el parser HC SI extrae `task.commit` del shape A+B+C, pero el componente Vue `SessionDetailModal.vue` (linea 353-357) renderiza solo `task.id` + `task.description` sin usar `task.commit`. El commit hash aparece visualmente solo como texto inline dentro de la descripcion (porque el markdown raw incluye "→ commit `5dc7e73`"). El dev pide que el commit hash sea visible en una zona dedicada y CLICKABLE para llevarlo al panel Commits donde puede ver el diff. Fix: agregar chip indigo con `task.commit` que llama `selectCommitByHash(shortHash)` → busca commit completo en `filteredCommits` → llama `selectCommit` → cambia al tab Commits y selecciona el hash.

## Discoveries / decisions

- D1: `SectionSessions.vue` y `SessionsSummaryTable.vue` NO renderizan tasks individualmente — delegan al modal. Solo `SessionDetailModal.vue` y `SpecSessionTree.vue` muestran `task.description`. Tactic tickets no tienen spec → SpecSessionTree fuera de scope
- M1 (micro-decision): chip es `<button>` (no `<a>`) porque cambia el tab y selecciona hash sin navegar. Estilo indigo con borde sutil + icono `⎘` para indicar "abrir/copiar". Tooltip muestra "Ver commit X en panel Commits". Alternativa rechazada: link a /commits/{hash}/diff — preferi mantener el dev en el modal y cambiar el tab, mas fluido
- M2 (micro-decision): `selectCommitByHash` busca por `shortHash === target` OR `hash.startsWith(target)` — robusto para hash truncados a 7 chars (formato shortHash de git)
