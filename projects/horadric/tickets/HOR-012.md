**Decisiones tomadas**:
- DEC-LOCAL-09: usar `reqwest` con feature `rustls-tls` (no openssl default) — evita dependencia del system OpenSSL en macOS, build mas predecible cross-version.
- DEC-LOCAL-10: tests de SIGKILL escalation con `perl` + `$SIG{TERM}='IGNORE'` — shell con `trap '' TERM` NO valida escalation porque SIGTERM mata al sleep hijo directo y el shell termina naturalmente al terminar el wait. Perl es un solo proceso que realmente ignora la senal, forzando SIGKILL.
- DEC-LOCAL-11: modulo Rust se llama `logging`, no `logs`. Motivo: el `.gitignore` del root de horadric-cube ya tiene `logs/` (output de logs del server Node en runtime). **Descubrimientos**:

- Race condition entre spawn y signal handler: perl necesita ~100-250ms para instalar `$SIG{TERM}` antes de que killpg llegue. Mitigado con sleep 250ms en el test. Para produccion (Fase 3b), el sidecar real (vite+tsx) tiene el mismo issue — el IPC command de stop debe esperar al menos el primer tick de `service:phase=ready` antes de permitir stop.
- H3 (health check con shape validation) ✓ validada completo en tests unitarios con wiremock.
