# Vista jerarquica de apps — App → Object → Layouts

## Request

El grafo de layouts muestra nodos y aristas pero no responde de un vistazo: "¿que apps hay, que objects entran por el sidebar de cada una, y que layouts conforman cada object?". Esa es la primera pregunta de un dev nuevo en UP1 y hoy requiere navegar el grafo a ojo.

Quiero una **vista jerarquica que pasa a ser el default** de LayoutsView. El grafo queda como modo alternativo accesible desde el toggle del toolbar. Ambos comparten store, filtros, DetailPanel y cross-link — es la misma data renderizada distinto.

Estructura del arbol:
- App (modName) → lista ordenada de Objects declarados en su `app.defaultObjects`
  - Object (objectName) → entry-point(s) primero (isNavigable), luego sub-layouts (mismo objectName, no entry-point)
    - Layout (id + layoutType + mode)

Grupo especial "Core + huerfanos" al final con:
- Layouts de `core:report-builder` y `core:defaults`
- Layouts sin `app` resuelto (no cruzaron con ningun `defaultObjects`)

## Decisiones

- **Default a Jerarquia**: responde la primera pregunta del dev nuevo ("¿que hay?") mejor que el grafo. Grafo responde "¿como se conecta?", util una vez entiendes la estructura. Persistencia en localStorage permite override permanente sin friccion.
- **Entry-point por layoutType, no por isNavigable**: BLY-007 marca toda la familia de un objectName como navegable para generar URLs; para la jerarquia eso junta demasiado. Tipos `RecordList`, `ChibiList`, `ImportTaskList`, `OfferingCalendar`, `AiChatbox` son entry-points; el resto (tipicamente `RecordDetail`) son sub-layouts.
- **`<details>` nativos (otra vez)**: patron consistente con el DetailPanel estructural (BLY-009). Accesibilidad gratis, sin Vue refs para estado de colapso.
- **Reuso de `useLayoutsStore`**: ambos modos consumen el mismo store, no hay estado duplicado. Seleccion, filtros y export funcionan igual en ambos.
- **Bucket "Otros"**: alternativa considerada — mezclar core y huerfanos con las apps. Rechazado porque confunde visualmente (no pertenecen a una app).
