**Discoveries / Learns:**

- **L1**: el Claude Agent SDK (`@anthropic-ai/claude-agent-sdk`) tiene una API simple de `query({ prompt, options })` que devuelve un AsyncGenerator de `SDKMessage`. El consumer itera, captura `assistant` blocks (texto), y opcionalmente lee `result` para metricas (cost). Sin tools, el flujo es 1 turn: prompt → respuesta → done.
- **L2**: para scripts CLI sin intervencion humana, lo mas seguro es `allowedTools: []` (sin tools). Eso evita que el SDK pida permisos via `canUseTool` y simplifica el flujo. Si se quieren tools, hay que combinar `allowedTools: [...]` con `canUseTool` callback o `permissionMode: 'bypassPermissions'` + `allowDangerouslySkipPermissions: true`.
- **L3**: `settingSources: []` en options evita que el SDK cargue settings del usuario o proyecto, lo cual hace el script reproducible y portable. Util para CI o scripts de utilidad.
- **L4**: `process.stderr.write()` para mensajes informativos del script (progreso, costo) y `process.stdout.write()` para el output del review permite hacer pipe-friendly: `npm run llm-review > review.md` solo escribe el review, mientras los logs van a stderr.
- **L5**: `git diff <base>...HEAD` (con triple punto) toma el diff respecto al merge base — comportamiento esperado para "que cambia esta branch sobre la base", aun si la base avanzo despues de bifurcar.

**Failed approaches:** ninguno significativo. La iteracion fue lineal una vez tomadas las decisiones DEC-LOCAL.
