## Request (original)

La vista Jerarquia (BLY-010) es optima para **escanear rapido** "que apps hay" pero pierde dos dimensiones importantes:

1. **Relaciones entre objects** dentro de una app (FKs, denorm refs) — hoy solo en Datamodel View, desconectadas de los layouts.
2. **Flujo entre layouts** dentro del mismo mod (rowAction → modal, record-list embebido → lista, associated → detalle) — hoy en vista Grafo pero mezclado con todas las apps.

Falta una vista de **zoom-in sobre una app puntual** que combine:

- Jerarquia visual (App como contenedor, Objects adentro agrupando sus Layouts)
- Aristas FK/denorm entre objects (heredadas de Datamodel)
- Aristas de navegacion entre layouts (heredadas del grafo actual)
- Layouts runtime mergeados (BLY-011)

## Idea de UX

Trigger: desde el tree de Jerarquia (BLY-010), boton "Ver mapa" al lado de cada App.

Render: Vue Flow con `parentNode` (grupos):

```
┌─────────────────────────────────────────────────────────┐
│ 📦 Hello World Mod                                       │
│                                                          │
│  ┌────────────┐       ┌────────────┐   ┌────────────┐  │
│  │HwAssessment│──FK──▶│  HwFactor  │   │HwIntervent.│  │
│  │ [RL] list  │       │ [RL] list  │   │ [RL] list  │  │
│  │ [RD] view  │       │ [RD] view  │   │ [RD] view  │  │
│  │ [RD] edit  │───┐   │ [RD] edit  │   │ [RD] edit  │  │
│  └────────────┘   │   └────────────┘   └────────────┘  │
│                   │                                      │
│         rowAction │                                      │
│              ▼                                           │
│         (abre edit)                                      │
└─────────────────────────────────────────────────────────┘
```

- Container = App (un nodo padre con label = modName)
- Interior = Objects del app (nodos hijos con tamaño fijo)
- Cada Object muestra su lista de Layouts en el cuerpo (tipo "card")
- Aristas:
  - Solid `→ FK` entre objects (heredado de Datamodel)
  - Dashed `→ navigation` entre layouts (heredado de vista Grafo: rowAction, record-list, associated)

## Scope

### IN

- Nuevo tab/modo en LayoutsView: `Mapa de app` (seleccionable solo cuando hay una app activa)
- Selector de app: dropdown o via click desde el tree
- Render con Vue Flow + `parentNode` agrupando objects en container-app
- Aristas FK entre objects (consume DataModel store)
- Aristas de navegacion entre layouts intra-app
- Layouts runtime (BLY-011) aparecen con badge `[DB]` igual que en tree
- Cross-link funcional: click en object → Datamodel; click en layout → DetailPanel

### OUT

- Edicion (sigue read-only)
- Vista "todas las apps en un canvas" — se descarta por saturacion con 30+ apps
- Overlays tipo heatmap, metricas visuales extra
- Export del mapa como imagen/PDF
