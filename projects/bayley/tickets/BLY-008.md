# Puente UP1 ↔ Bayley: pegar URL de UP1 y ver el layout en el grafo

## Request

Cuando un dev esta trabajando en UP1 real y ve una vista en `http://localhost:3000/UPU/CaCompetencyMatrix/RecordList/ca_matrix_list`, quiere poder saltar a Bayley con ese layout seleccionado y centrado — sin tener que buscar manualmente por el id.

Dos formas complementarias:
- **Input en TopBar** de la vista Layouts: pegar URL de UP1 → parsea → selecciona layout
- **Deep-link** `/layouts?from=<url-up1>` para compartir links que abren Bayley en un layout especifico desde un bug report o PR review

## Formato de URL UP1

```
http://localhost:3000/{tenant}/{objectName}/{layoutType}/{layoutId}
```

Ejemplos:
- `http://localhost:3000/UPU/CaCompetencyMatrix/RecordList/ca_matrix_list`
- `http://localhost:3000/TEST/CaLevelScheme/RecordDetail/ca_levelscheme_view`

Tambien aceptar variantes:
- Sin protocolo: `localhost:3000/UPU/...`
- Solo path: `/UPU/CaCompetencyMatrix/RecordList/ca_matrix_list`
- Con query/hash al final: `/UPU/.../ca_matrix_list?foo=bar#section`

Parser debe:
1. Extraer path ignorando host/protocolo/query/hash
2. Validar el patron de 4 segmentos
3. Retornar `{tenant, objectName, layoutType, layoutId}` o error

## Artifacts

### Composable nuevo

`src/composables/useUp1UrlParser.ts`:

```typescript
export interface Up1UrlParts {
  tenant: string;
  objectName: string;
  layoutType: string;
  layoutId: string;
}

export type ParseResult =
  | { ok: true; parts: Up1UrlParts }
  | { ok: false; error: string };

export function parseUp1Url(raw: string): ParseResult;
```

Regex:
```
^(?:https?:\/\/)?(?:[^\/]+)?\/([^\/?#]+)\/([^\/?#]+)\/([^\/?#]+)\/([^\/?#]+?)(?:[?#].*)?$
```

Captura: tenant, objectName, layoutType, layoutId.

### Handler en LayoutsView

```typescript
function onUp1Navigate(parts: Up1UrlParts) {
  // 1. Buscar layout en el modelo
  const target = model.value?.nodes.find(n => n.id === parts.layoutId);
  if (!target) {
    // toast error: "layout no encontrado"
    return;
  }
  // 2. Seleccionar + auto-filtrar
  store.selectLayout(target.id);
  store.objectFilter = new Set([target.objectName]);
  // 3. Warning si no navegable
  if (!target.isNavigable) {
    // toast warning
  }
  // 4. Persist en localStorage (ultimas 3 URLs)
  addToRecent(/* url original */);
}
```

### Deep-link

En onMounted del LayoutsView:
```typescript
const from = route.query.from as string | undefined;
if (from) {
  const res = parseUp1Url(from);
  if (res.ok) onUp1Navigate(res.parts);
  // limpia el query param
  router.replace({ path: '/layouts', query: { layout: res.parts?.layoutId } });
}
```
