- **Warnings detectados por research**:
  - Bayley parsea hoy `datamodel`, `permisos`, `i18n` — **NO parsea forms, recordlist, flows, events**. Esto es greenfield para todos los hallazgos.

  - El parser de i18n asume archivos `{locale}.json` planos. Los nuevos archivos `{locale}@{object}.json` no se ven con el patron actual — posible **silently missed coverage**.
  - El objeto `N8nWorkflow` es referencia abierta (no FK DB) — el parser de relaciones puede no detectar el vinculo.
