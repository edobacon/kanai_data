## Pedido

Agregar una utilidad que "grita" un texto, en el sandbox.

1. **Código**: crear `shout.mjs` que exporte `shout(text, { marks } = {})`.
   - Devuelve el texto recortado (trim) en mayúsculas seguido de signos de exclamación; la cantidad de signos la define `marks` (por defecto 1).
   - Ejemplo: shout('hola') devuelve 'HOLA!' y shout(' hola ', { marks: 3 }) devuelve 'HOLA!!!'.
   - Si el texto viene vacío (o solo espacios, undefined o null), lanza un `Error` con un mensaje que menciona text.
   - Si marks no es un entero mayor o igual a 1, lanza un `RangeError`.
2. **Tests**: agregar `shout.test.mjs` con `node --test` que cubra: el default, marks configurable, el trim, el texto vacío y marks inválido.
3. **Documentación**: documentar el uso de `shout` en el README, con un ejemplo, sin reescribir lo existente.

## Fuera de alcance

- No modificar `greet.mjs` ni sus tests.

Ticket de prueba de la ejecución por sesión encadenada. Conviene planificar código, tests y documentación como tareas separadas de una misma sesión.
