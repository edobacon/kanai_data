## Pedido

Agregar una función de despedida al sandbox, análoga a `greet.mjs`.

1. **Código**: crear `farewell.mjs` que exporte `farewell(name, { punctuation } = {})`.
   - Devuelve `Adiós, <nombre><puntuación>`; la puntuación por defecto es `.`.
   - Hace trim del nombre.
   - Si el nombre viene vacío (o solo espacios), lanza un `Error` con un mensaje claro.
2. **Tests**: agregar `farewell.test.mjs` con `node --test` que cubra: el default, la puntuación configurable, el trim y el nombre vacío.
3. **Documentación**: documentar el uso de `farewell` en el README, con un ejemplo.

## Fuera de alcance

- No modificar `greet.mjs` ni sus tests.

Ticket de prueba para validar la ejecución por sesión encadenada (un subagente por sesión, un checkpoint por tarea). Conviene planificar código, tests y documentación como tareas separadas de una misma sesión.
