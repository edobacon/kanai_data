# Decidir R2: confirmar uso en algun deploy, luego borrar dead code o cubrir con test

## Request

Derivado de la auditoria de migracion (2026-07-19), punto debil #5. El adapter `CloudflareR2Storage` (`server/utils/storage/r2.ts`) esta wireado en el factory pero **nunca se activa** (todos los ambientes resuelven a `local`), y no tiene ningun test (la cobertura de storage es 100% sobre `LocalStorage`/factory). Es un riesgo bifurcado: si algun deploy de produccion usa R2, un bug ahi no lo detecta ningun test; si ningun deploy lo usa, es dead code. Este ticket resuelve la ambiguedad.
